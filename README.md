# vdisk

This is a SHIM repository used to hold a VDISK docker image that will stand in place for Foundry

As a SYSTEM Foundry will bind 
 + VDISK
 + VCONSOLE
 + Switchard
 + arch-nod
   * t32-node
   * arm7-node 
   * x64-node 

   So VDISK will be a component.  This is SHIM for the moement.  It might be the case this is developed more or just deleted because it ends up collapsing into the Foundry.
